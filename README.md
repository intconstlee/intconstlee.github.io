# 门与指令 · GATES & INSTRUCTIONS

一个纯静态的交互式数字系统学习站，依据《数字设计和计算机体系结构》（原书第 2 版）与《知识点精讲》编写。

建议桌面阅读宽度 1280px 以上；手机与平板已适配。

## 内容规模

- 8 个正文章节 + 1 个速查台
- 122 个知识点小节
- 36 幅不同的知识点矢量示意图，在正文和速查台共引用 44 次
- 412 道习题
- 100 道可交互实验题

## 交互实验

- **逻辑门电路**：拖动 / 点击门，从端口拖线，按真值表逐行仿真并校验；可载入参考电路。
- **SystemVerilog**：内置组合逻辑判题器，支持 `assign`、`always_comb`、`if`、`case`、位选、拼接、三目等；逐组测试用例验证。
- **MIPS 汇编**：内置 MIPS32 解释器，支持核心指令与常用伪指令、数据段、栈与函数调用；按寄存器 / 内存期望值判分。
- **卡诺图**：点击格点圈组，校验矩形合法、覆盖完整、组数最简，并给出化简式。
- **时序波形**：点击 / 拖动编辑波形，按器件语义逐片比对。
- **排序 / 配对 / 位开关 / 位域编码**：拖动排序、拖动配对、位开关、指令与 Cache 地址位域编码。

## 学习记录

学习记录用于阅读进度、答题统计、错题本与练习续做。

- 记录保存在当前浏览器的 `localStorage`（键：`gates-instructions.v1`）
- 不登录、不上传、没有账号体系
- 换浏览器、换设备或清除站点数据后记录不会同步
- 学习统计页提供「清空学习记录」

发布包本身不包含任何预置的学习记录；首次打开时记录为空。

## 键盘与快捷操作

- `Ctrl / ⌘ + K`：搜索知识点与题目
- 答题时 `1`–`4` 选择选项，`Enter` 检查 / 下一题
- 代码编辑器 `Tab` 缩进，`Ctrl / ⌘ + Enter` 运行测试
- 章节页点击目录跳转，滚动记录已读
- 右上角可切换深色模式

## 设计

- 每页一个主题色相，页面内用同一色相的 6 级明度（s0–s5）区分内容层次
- 无渐变、无装饰性描边；用色块和留白组织信息
- 章节页采用大色块 filled hero，练习与速查使用 tonal header
- 标题与装饰性数字使用本地打包的 Space Grotesk 几何字体；正文（含题干、表格）数字跟随正文西文字体
- 知识点示意图与页面共用 s0–s5 色阶，不引入第二种色相
- 响应式：桌面 / 平板 / 手机

## 数据与判题

- 所有内容只依赖本项目内的电子课本与知识点精讲；无外部 CDN、字体或图片依赖。
- 习题包含 14 种题型；校验脚本检查结构、答案、交互参数与参考解一致性。
- 交互题参考解可通过「示例解 / 参考解 / 参考圈法 / 参考答案 / 填入参考值」载入。

## 已知边界

- HDL 判题器只覆盖**组合逻辑**（不含时序块、`initial`、实例化等）。
- MIPS 解释器覆盖教学所需的核心指令子集与常用伪指令。
- 学习记录仅保存在本机浏览器；清除站点数据会一并清除。
- 深色模式跟随系统并可手动切换；两种模式使用同一套色相层级。
